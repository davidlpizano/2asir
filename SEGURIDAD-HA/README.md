# Seguridad y Alta Disponibilidad

Esta asignatura aborda la protección de sistemas y servicios, así como las
medidas necesarias para mantenerlos operativos ante fallos y contingencias.

## Contenidos

Los temas y materiales de la asignatura se irán incorporando durante el curso.

## Objetivo

Se busca comprender tanto la seguridad aplicada como la continuidad y
resiliencia de los servicios.
