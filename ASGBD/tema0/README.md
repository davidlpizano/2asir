# Tema 0: Repaso de bases de datos

Repaso de los conceptos y operaciones SQL necesarios para trabajar con bases
de datos relacionales antes de comenzar la programación con PL/SQL.

## Contenidos

1. **Creación de tablas:** definición de columnas, tipos de datos y
   restricciones.
2. **Modificación de tablas:** cambios en la estructura, como añadir,
   modificar o eliminar columnas y restricciones.
3. **Introducción y modificación de datos:** inserción, actualización y
   eliminación de registros.
4. **Consultas:** recuperación y filtrado de información con `SELECT`,
   ordenación y combinación de tablas.
