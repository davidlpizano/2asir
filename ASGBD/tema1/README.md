# Tema 1: PL/SQL

Introducción a PL/SQL, el lenguaje procedimental de Oracle que amplía SQL con
variables, estructuras de control y mecanismos para organizar la lógica de
base de datos.

## Contenidos

1. **Estructura de un bloque PL/SQL:** declaraciones, instrucciones y manejo de
   excepciones.
2. **Variables y tipos de datos:** declaración, asignación y uso de variables.
3. **Estructuras de control:** condiciones y bucles.
4. **Cursores:** recorrido y procesamiento de resultados de consultas.
5. **Subprogramas:** procedimientos y funciones.
6. **Excepciones:** gestión de errores durante la ejecución.
