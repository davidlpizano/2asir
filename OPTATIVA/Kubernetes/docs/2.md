# 2. Instalación

[Volver al índice](../README.md)

La instalación de Kubernetes puede realizarse en entornos locales, pruebas o
servidores reales. Dependiendo del caso de uso, se puede optar por herramientas
como `kubeadm`, `kind`, `minikube` o distribuciones gestionadas.

## Opción recomendada para empezar

Para practicar en local, es habitual utilizar:

- **minikube**: entorno ligero para ejecutar un clúster local
- **kind**: crea clústeres Kubernetes usando contenedores Docker
- **kubeadm**: herramienta más avanzada para desplegar clústeres en nodos
  reales o máquinas virtuales

### Instalación de Minikube en Linux

Descarga el binario más reciente para Linux e instálalo en `/usr/local/bin`:

```bash
curl -LO https://github.com/kubernetes/minikube/releases/latest/download/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube && rm minikube-linux-amd64
```

### Instalación de kubectl

Con el binario `kubectl` descargado en el directorio actual, instálalo en
`/usr/local/bin`:

```bash
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
```

## Requisitos básicos

Antes de instalar Kubernetes, es necesario comprobar que la infraestructura
cumple requisitos mínimos:

- sistema operativo compatible
- acceso de administrador
- soporte de contenedores
- red configurada correctamente
- suficientes recursos de CPU y memoria

## Verificación

Tras la instalación, se puede comprobar la salud del clúster con comandos como:

```bash
kubectl version --client
kubectl get nodes -o wide
kubectl cluster-info
```

`kubectl version --client` comprueba la instalación del cliente. Los comandos
`kubectl get nodes -o wide` y `kubectl cluster-info` requieren que haya un
clúster en ejecución y que el contexto de acceso esté configurado.

## Activación del autocompletado

Para activar el autocompletado de `kubectl` y `minikube` en Bash en futuras
sesiones, añade las siguientes líneas a `~/.bashrc`:

```bash
echo 'source <(kubectl completion bash)' >> ~/.bashrc
echo 'source <(minikube completion bash)' >> ~/.bashrc
```

Aplica la configuración en la sesión actual:

```bash
source ~/.bashrc
```
