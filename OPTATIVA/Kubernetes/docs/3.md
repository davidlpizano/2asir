# 3. Pods

[Volver al índice](../README.md)

Un pod es la unidad básica de ejecución en Kubernetes. Agrupa uno o varios
contenedores que comparten recursos de red y almacenamiento y se gestionan como
una sola entidad.

## Características de un pod

- es la unidad más pequeña que puede desplegarse
- puede contener varios contenedores relacionados
- comparte una IP y un namespace de red
- puede tener volúmenes persistentes o temporales

## Ejemplo básico

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: mi-pod
spec:
  containers:
    - name: app
      image: nginx:latest
      ports:
        - containerPort: 80
```

Este ejemplo crea un Pod que ejecuta un contenedor Nginx. En la práctica, los
Pods suelen gestionarse a través de Deployments para obtener más control y
escalabilidad.

## Ciclo de vida

Un pod puede pasar por diferentes estados: pendiente, en ejecución, fallido o
suspendido. Kubernetes vigila su estado y toma decisiones de reinicio o
replanificación según sea necesario.
