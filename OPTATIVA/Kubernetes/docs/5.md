# 5. Deployments

[Volver al índice](../README.md)

Los Deployments son la forma recomendada de gestionar aplicaciones en Kubernetes.
Definen el estado deseado de la aplicación y Kubernetes se encarga de mantenerlo.

## Características principales

- despliegue declarativo
- escalado automático o manual
- actualizaciones progresivas
- rollbacks ante errores
- control centralizado del estado deseado

## Ejemplo

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
        - name: nginx
          image: nginx:latest
          ports:
            - containerPort: 80
```

## Comandos útiles

```bash
kubectl get deployments
kubectl describe deployment nginx-deployment
kubectl rollout status deployment/nginx-deployment
```

Los Deployments permiten desplegar nuevas versiones de la aplicación sin
interrumpir el servicio de forma drástica y con posibilidad de revertir cambios.
