# 2.º de ASIR

Repositorio principal con apuntes, prácticas y materiales de las asignaturas
del segundo curso del ciclo de Administración de Sistemas Informáticos en Red.

## Asignaturas

| Asignatura | Contenidos |
| --- | --- |
| [Administración de Sistemas Operativos (ASO)](ASO/README.md) | Administración y programación de tareas en sistemas operativos. |
| [Administración de Sistemas Gestores de Bases de Datos (ASGBD)](ASGBD/README.md) | Creación y administración de bases de datos y programación con PL/SQL. |
| [Servicios en Red](SERVICIOS-EN-RED/README.md) | Servicios de red como DNS y DHCP, y su despliegue. |
| [Seguridad y Alta Disponibilidad](SEGURIDAD-HA/README.md) | Seguridad de sistemas y servicios, y continuidad ante fallos. |
| [Optativa](OPTATIVA/README.md) | Contenidos optativos del curso. |
