# 2.º de ASIR

Este repositorio reúne los apuntes, prácticas y materiales del segundo curso
de Administración de Sistemas Informáticos en Red (ASIR).

Está organizado por asignaturas para facilitar el estudio y la consulta rápida
según el tema o la materia.

## Navegación rápida

| Asignatura | Qué se estudia |
| --- | --- |
| [Administración de Sistemas Operativos (ASO)](ASO/README.md) | Administración de sistemas, scripting, automatización y tareas del sistema. |
| [Administración de Sistemas Gestores de Bases de Datos (ASGBD)](ASGBD/README.md) | Diseño, administración y consulta de bases de datos, además de PL/SQL. |
| [Implantación de Aplicaciones Web (IAW)](IAW/README.md) | Instalación y configuración de servidores web y aplicaciones web. |
| [Servicios en Red](SERVICIOS-EN-RED/README.md) | DNS, DHCP, alta disponibilidad y despliegue de servicios en red. |
| [Seguridad y Alta Disponibilidad](SEGURIDAD-HA/README.md) | Seguridad de sistemas, servicios y continuidad ante fallos. |
| [Optativa](OPTATIVA/README.md) | Contenidos complementarios y recursos optativos del curso. |

## Cómo usarlo

- Consulta la carpeta de la asignatura que necesites.
- Dentro de cada módulo encontrarás los temas y documentos relacionados.
- El contenido se va ampliando a lo largo del curso, así que algunos apartados
  pueden estar en desarrollo.
