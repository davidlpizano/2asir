# Implantación de Aplicaciones Web (IAW)

Esta asignatura centra el estudio de la instalación, configuración y
administración de servidores web y aplicaciones web.

## Contenidos

| Tema | Enfoque |
| --- | --- |
| [Tema 1: Instalación de servidores de aplicaciones web](tema1/README.md) | Fundamentos de la Web, cliente-servidor, formularios HTML y protocolo HTTP. |
| [Tema 2: Programación en PHP](tema2/README.md) | Sintaxis PHP, validación de formularios, cookies, sesiones y control de acceso. |
| [Tema 3: Acceso a bases de datos desde el lenguaje servidor](tema3/README.md) | Conexión con PDO, SQL, CRUD, seguridad, sesiones y optimización de consultas. |

## Estado

El material se desarrolla durante la asignatura y se va ampliando progresivamente.
